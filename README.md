## 🎨 The Portfolio Experience

This isn't just a collection of projects and achievements. It's an interactive experience inspired by the visual storytelling of comic books.

### ✨ Key Features

- **Cinematic Introduction** — A Marvel-inspired opening featuring an animated photography carousel behind the RONAK wordmark.
- **Comic-Book UI** — Bold typography, halftone textures, vibrant panels, pop-art colors, and dramatic outlines.
- **Light & Dark Mode** — Two themes with responsive colors and contrast.
- **Interactive Projects** — A showcase of technical projects and development work.
- **Experience Timeline** — Industry internships, council leadership, marketing roles, and freelance work.
- **Events & Leadership** — Hackathons, workshops, competitions, and events I've organised.
- **Achievements & Participation** — Competition results, awards, certificates, and events I've participated in.
- **Certificate Viewer** — An integrated document viewer for certificates and internship letters.
- **Photo Gallery** — Click-to-expand event and achievement photographs.
- **Responsive Design** — Designed for desktop, tablet, and mobile.

## 🛠️ Tech Stack

## 💻 Running Locally

**1. Clone the repository**

```bash
git clone https://github.com/ronakshah167/portfolio.git
cd portfolio
```

**2. Start a local server**

```bash
python3 -m http.server 8000
```

**3. Open the website**

Visit:

```text
http://localhost:8000
```

No dependency installation or build process is required.
